There are multiple types of shells for Unix-based Operating Systems. The most common and default shell of Linux is Bash. The more modern and default shell of MacOS(since 2017) is zsh.


Common Linux commands include:

| command  | description                                                                                                                                                                                                                                                | example                                                                                |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `ls [dir]` | Lists files and folders in a given directory. Optional file path argument to specify directory to list, otherwise it will use the current working directory.
