The terminal is a text interface for your system. When you type and enter a command, the shell executes them and prints the result.
The program interpreting your commands is called a shell. On most Linux systems, thats `bash` or `zsh`. On MacOS, as of October 2019, the shell used is `zsh`.

When you open a terminal, you're inside:
* A user session
* A current working directory
* A running shell process
Understanding those three things prevents most mistakes beginners make.

**One important note is that most commands, especially filesystem related ones, are non-verbose by default. They do not print any output if they succeed. You will have to check manually. (e.g. through `ls`)**
## The prompt
You'll see something like this:

`user@machine:~$`

This tells you:
* `user` - your username, which you can alternatively check with the `whoami` command.
* `machine` - your hostname, which you can check with `hostname`.
* `~` - your current working directory (CWD), which you can check with `pwd`. Note that `~` is a shorthand for `/home/user`.
* `$` - normal user. If you're in root, you would see `#`.

Some Linux distros may show more or less information in different formats, though it will almost always show the username, machine, CWD and privilege mode.

## Where you are
The directory you're inside of is called the "current working directory".
Using `pwd`, which essentially means "Print Working Directory".

The shell always runs code relative to your current location unless you specify an absolute path.

<CodeBlock language="shellsession" code={`user@machine:~$ pwd\n/home/user`} />

## Changing directories
To move to a directory, you use `cd`.

<CodeBlock language="shellsession" code={`user@machine:/$ ls home\nuser@machine:/home$`}/>

`.` refers to the current directory, and `..` refers to the parent directory.

For instance, if you're in `~` and wish to go back one-level.

<CodeBlock language="shellsession" code={`user@machine:~$ cd ..\nuser@machine:/home$`}/>
Note that since `~` is a shorthand for `/home/user`, when you go to its parent directory, it says `/home`.

## Absolute vs Relative paths

Absolute paths are paths that start from the root (`/`).
For instance, `/home/user/Documents` is an absolute path.
Relative paths are paths relative to the CWD. For instance, If you're in `~`, the same directory would instead be `Documents`.

Note that file paths in UNIX are case-sensitive. `Documents` is not the same as `documents`.

## Creating and removing files

Creating an empty file is done through `touch`.
<CodeBlock language="shellsession" code={`user@machine:~$ touch example.txt\n\nuser@machine:~$ ls\nexample.txt`}/>

To create a directory, similar to windows, you can use `mkdir`.
<CodeBlock language="shellsession" code={`user@machine:~$ mkdir example\n\nuser@machine:~$ ls\nexample`}/>

To remove a folder, you can use `rmdir`. Do note that the folder must be empty.
<CodeBlock language="shellsession" code={`user@machine:~$ rmdir example\n\nuser@machine:~$ ls\n`}/>

To remove a file, you can use `rm`. You should be careful with `rm` as it does not delete to a trashbin.
<CodeBlock language="shellsession" code={`user@machine:~$ rm example.txt\n\nuser@machine:~$ ls\n`}/>
Note that the `rm` command can be used to delete folders too if you utilize the `-r`(recursive) flag. You can also use the `-f` flag to force deletion.
<CodeBlock language="shellsession" code={`user@machine:~$ ls example\nexample.txt  file1.txt  file2.txt  folder1  folder2\nuser@machine:~$ rm -rf example\n\nuser@machine:~$ ls\n`}/>
